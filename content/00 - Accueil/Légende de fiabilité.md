# Légende de fiabilité

| Niveau | Usage |
|---|---|
| 🟢 Confirmé | Fait établi, observation directe solide ou donnée archivistique considérée comme fiable |
| 🟡 Plausible / partiel | Élément cohérent mais incomplet, attribution, datation estimée ou témoignage crédible |
| 🔵 Incertain / rumeur | Rumeur, souvenir imparfait, témoignage non recoupé ou hypothèse faible |
| 🔴 Réfuté / problématique | Élément infirmé, contradictoire ou manifestement erroné |
| ❓ Inconnu | Question ouverte |

## Règle d'or

**Une information et sa source sont deux choses différentes.**

Une note peut conserver une affirmation sans l'adopter comme vérité. Les contradictions doivent être conservées, pas effacées.
