# Théorie - Les manifestations célestes de Vifazur sont liées

## Éléments favorables

- deux phénomènes à douze jours d'intervalle ;
- apparence circulaire ou tourbillonnante ;
- événements occultes proches dans le temps.

## Éléments contraires / inconnus

- couleurs très différentes ;
- acteurs différents ;
- aucune preuve d'une destination ou d'un créateur commun.

Les deux événements doivent être reliés dans le graphe sans être fusionnés.
