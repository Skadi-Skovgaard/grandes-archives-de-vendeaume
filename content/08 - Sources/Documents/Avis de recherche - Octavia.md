# Avis de recherche - Octavia

Deux avis de recherche concernant [[Octavia]] sont conservés dans les Archives.

## Avis gravé

![[920cb838-8baf-45a6-b507-ccb18b7a843e.png]]

Cet avis indique notamment :

- nom : Octavia ;
- sexe : féminin ;
- Seigneur Vampire ;
- très dangereuse ;
- cheveux noirs courts ;
- visage pâle ;
- maquillage sur le visage ;
- vêtements noirs et tenue élégante ;
- comportement décrit comme calme, cruel et froid.

Le document indique **« race : Bretonne »**. Cette mention n'est pas retenue comme correcte dans la fiche d'Octavia.

## Communiqué officiel du Penitus Oculatus

![[1bba5a3b-e4a7-4fee-81e4-42faae12523b.png]]

Le communiqué indique notamment :

- nom : Octavia ;
- race : **Impériale** ;
- Seigneur Vampire ;
- tatouage noir ornemental sous l'œil gauche ;
- cicatrice verticale sous l'œil droit ;
- capuche sombre et vêtements de style gothique, généralement sombres ;
- usage rapporté de manipulation, d'illusion et de séduction.

Il demande que toute information soit signalée aux agents du Penitus Oculatus, aux légionnaires, aux Vigiles de Stendarr, à la Garde de l'Aube ou à la Main d'Argent.

## Note des Archives

La race retenue pour Octavia est **Impériale**. La mention « Bretonne » du premier avis est conservée comme erreur documentaire.
