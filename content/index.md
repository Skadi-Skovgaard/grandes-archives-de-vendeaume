## Principe de classement

Une information n'est jamais considérée comme vraie uniquement parce qu'elle apparaît dans une note.

Toujours distinguer :
- **fait établi** ;
- **observation directe** ;
- **témoignage** ;
- **rumeur** ;
- **tradition** ;
- **hypothèse / théorie** ;
- **information réfutée ou contradictoire**.
